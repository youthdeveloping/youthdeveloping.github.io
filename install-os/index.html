운영체제 설치 가이드

USB 제작부터 부팅, 설치, 드라이버, 설치 후 점검까지 단계별로 알아보세요.

필독: 설치 USB 제작은 USB 내부 데이터를 삭제할 수 있고, 운영체제 설치 중 파티션 삭제·포맷은 기존 파일을 지울 수 있습니다. 백업과 대상 디스크 확인을 먼저 하세요. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

처음 설치하는 분께

  1. 컴퓨터 모델과 호환되는 운영체제를 선택합니다.
  2. 공식 사이트에서 ISO/설치 도구를 다운로드합니다.
  3. 빈 USB를 준비하고 해당 OS에 맞는 이미지 작성 도구로 부팅 매체를 만듭니다.
  4. 부팅 메뉴에서 USB를 선택해 설치 프로그램을 실행합니다.
  5. 디스크 설정을 신중히 확인하고 설치 후 업데이트·드라이버·백업을 점검합니다.

Windows (11)

  • Windows 98 설치 안내 — 정품 CD와 당시 하드웨어가 필요할 수 있는 구형 OS입니다.
  • Windows XP 설치 안내 — 오래된 프로그램과 레거시 PC를 위한 설치 안내입니다.
  • Windows Vista 설치 안내 — 호환되는 구형 PC에서만 설치를 검토하세요.
  • Windows 7 설치 안내 — 드라이버와 부팅 방식 호환성을 확인하고 설치하세요.
  • Windows 8 설치 안내 — Windows 8 설치와 라이선스 에디션을 확인하는 안내입니다.
  • Windows 8.1 설치 안내 — Windows 8과 별도인 Windows 8.1 설치 안내입니다.
  • Windows 10 설치 안내 — Microsoft 미디어 생성 도구를 사용해 USB를 만들고 설치하는 절차입니다.
  • Windows 11 설치 안내 — 공식 Windows 11 미디어 생성 도구로 USB를 만들고 설치합니다.
  • Windows 95 설치 안내 — Windows 95는 정품 매체와 호환 구형 PC 또는 가상 머신이 필요한 매우 오래된 OS입니다.
  • Windows 2000 설치 안내 — Windows 2000은 레거시 업무 프로그램을 위한 구형 OS입니다.
  • Windows Me 설치 안내 — Windows Me는 당시 가정용 PC를 위한 레거시 OS입니다.

Linux 배포판 (8)

  • Ubuntu 설치 안내 — Ubuntu는 라이브 USB로 먼저 시험한 뒤 설치할 수 있습니다.
  • Debian 설치 안내 — Debian은 설치 프로그램에서 파티션과 데스크톱 환경을 선택할 수 있습니다.
  • Linux Mint 설치 안내 — Linux Mint는 친숙한 데스크톱을 제공하는 Linux 배포판입니다.
  • Fedora Workstation 설치 안내 — Fedora Workstation은 최신 데스크톱 Linux 기술을 제공하는 배포판입니다.
  • Arch Linux 설치 안내 — Arch Linux는 파티션, 부트로더와 시스템을 직접 구성하는 고급 사용자용 OS입니다.
  • openSUSE 설치 안내 — openSUSE는 YaST 구성 도구와 여러 데스크톱 환경을 제공하는 배포판입니다.
  • Zorin OS 설치 안내 — Zorin OS는 데스크톱 사용 편의성을 중시하는 Linux 배포판입니다.
  • elementary OS 설치 안내 — elementary OS는 간결한 데스크톱 환경을 제공하는 Linux 배포판입니다.

기타 운영체제 및 서버 (6)

  • macOS 설치 안내 — macOS는 호환되는 Apple Mac에서 공식 복구 또는 부팅 가능한 설치 USB로 설치합니다.
  • Windows Server 2022 설치 안내 — Windows Server 설치는 역할 구성과 네트워크 보안 계획까지 필요합니다.
  • ChromeOS Flex 설치 안내 — ChromeOS Flex는 지원되는 PC/Mac용 ChromeOS 계열 OS입니다.
  • Raspberry Pi OS 설치 안내 — Raspberry Pi OS는 Raspberry Pi 보드용 공식 운영체제이며 microSD 카드에 기록합니다.
  • FreeBSD 설치 안내 — FreeBSD는 Linux와 다른 BSD 계열 운영체제입니다.
  • Proxmox VE 설치 안내 — Proxmox VE는 가상 머신과 컨테이너를 관리하는 가상화 서버 플랫폼입니다.

안전한 설치 원칙

  • 지원 종료 OS는 오프라인 또는 격리된 환경에서 사용합니다.
  • macOS는 호환되는 Apple Mac의 공식 복구·설치 절차를 이용합니다.
  • ChromeOS Flex는 Google의 인증 모델 목록을 먼저 확인합니다.
  • 서버와 고급 Linux는 가상 머신에서 먼저 연습하는 것이 좋습니다.
