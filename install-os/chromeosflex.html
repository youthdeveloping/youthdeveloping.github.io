ChromeOS Flex 설치 방법

기타 · 설치 준비부터 설치 후 점검까지

ChromeOS Flex는 지원되는 PC/Mac용 ChromeOS 계열 OS입니다.

시작하기 전에
설치 시 내부 저장장치의 데이터가 삭제될 수 있습니다. 모든 모델과 Chromebook 기능을 지원하지는 않습니다.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. Google 인증 모델 목록에서 PC 모델을 확인합니다.
  2. 다른 PC의 Chrome 브라우저에 Chromebook Recovery Utility를 설치합니다.
  3. 8GB 이상 USB를 연결하고 유틸리티에서 Google ChromeOS Flex를 선택해 USB를 만듭니다. USB 데이터가 삭제됩니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: ChromeOS Flex 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. 대상 PC를 종료하고 USB를 연결합니다.
  2. 전원을 켜며 제조사 부팅 메뉴 키를 눌러 USB를 선택합니다.
  3. 가능하면 먼저 사용해 보기 모드에서 Wi‑Fi·키보드·화면을 시험합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치를 결정하기 전에 파일을 백업합니다.
  2. 화면의 Install ChromeOS Flex를 선택합니다.
  3. 내부 저장장치 삭제 경고와 대상 기기를 확인한 뒤 설치를 진행합니다.
  4. 설치 후 USB를 제거하고 재부팅합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 네트워크에 연결하고 초기 설정을 완료합니다.
  2. 모델별 기능 제한과 인증 상태를 확인합니다.

6. 문제 해결

  1. 부팅 실패 시 USB를 다시 만들고 다른 포트를 시험합니다.
  2. Wi‑Fi/오디오 문제는 인증 모델 목록과 알려진 문제를 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
