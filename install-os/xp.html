Windows XP 설치 방법

Windows 구형 · 설치 준비부터 설치 후 점검까지

오래된 프로그램과 레거시 PC를 위한 설치 안내입니다.

시작하기 전에
지원 종료 OS입니다. 웹, 이메일, 계정 로그인, 결제에 사용하지 말고 오프라인 환경을 권장합니다.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. PC 모델과 SATA/AHCI 저장장치 지원을 확인합니다.
  2. 중요 파일을 백업하고 정품 CD, 라이선스, 호환 드라이버를 준비합니다.
  3. 구형 PC에서는 CD/DVD 설치가 USB 설치보다 호환성이 좋을 수 있습니다.
  4. USB 제작은 PC가 USB 부팅을 지원하는지 먼저 확인하고, ISO를 단순 복사하지 않습니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Windows XP 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. BIOS/부팅 메뉴에서 CD/DVD 또는 호환 USB를 선택합니다.
  2. CD 부팅 문구가 나오면 안내된 키를 누릅니다.
  3. 설치 화면이 열리지 않으면 부팅 매체와 부팅 순서를 다시 확인합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 프로그램을 시작하고 라이선스 안내를 확인합니다.
  2. 설치 대상 파티션을 선택합니다. 삭제·포맷은 해당 파티션의 데이터를 지웁니다.
  3. 디스크가 표시되지 않으면 저장장치 드라이버가 필요한지 확인합니다.
  4. 화면 안내에 따라 파일 복사, 재부팅, 시간대·제품 키·사용자 설정을 완료합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 호환 칩셋·그래픽·오디오·네트워크 드라이버를 설치합니다.
  2. 장치 관리자에서 알 수 없는 장치를 확인합니다.
  3. 네트워크 연결을 끄거나 격리합니다.

6. 문제 해결

  1. 디스크 미표시는 저장장치 드라이버/컨트롤러 호환성을 확인합니다.
  2. USB 부팅 실패 시 정품 CD/DVD 사용을 검토합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
