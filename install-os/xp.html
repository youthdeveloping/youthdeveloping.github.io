Windows XP 설치 방법

중급 · 레거시 환경 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows XP는 구형 PC 또는 오래된 프로그램의 호환성 목적에 한해 설치를 검토할 수 있습니다.

설치 전 반드시 읽어 주세요
지원이 종료된 운영체제입니다. 인터넷, 이메일, 계정 로그인, 결제 등 민감한 작업에 사용하지 마세요. 정품 매체와 유효한 라이선스를 사용하세요.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. PC 모델과 CPU 아키텍처, BIOS/UEFI 모드, 저장장치 종류를 확인합니다. 일부 SATA/AHCI 컨트롤러는 XP 설치 프로그램에서 기본 지원되지 않습니다.
  2. 파일을 백업하고 정품 설치 CD, 제품 키, 필요 드라이버를 준비합니다.
  3. USB 설치를 시도하기 전 해당 PC가 USB 부팅을 지원하는지 확인합니다. 오래된 PC에서는 정품 CD/DVD가 더 안정적일 수 있습니다.
  4. USB를 사용할 경우 신뢰할 수 있는 설치 이미지와 PC에 맞는 제작 방법을 사용합니다. USB에 파일을 복사하는 것만으로는 부팅 미디어가 되지 않습니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. PC 전원을 켜고 제조사 부팅 메뉴 키를 누르거나 BIOS 설정에 들어갑니다.
  2. CD/DVD 또는 호환 USB 장치를 첫 부팅 장치로 선택하고 저장 후 재시작합니다.
  3. 'Press any key to boot from CD'와 같은 문구가 나오면 안내에 따라 키를 누릅니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 프로그램이 파일을 로드한 뒤 안내를 표시하면 Enter 등 화면에 지정된 키를 눌러 설치를 시작합니다.
  2. 라이선스 안내를 확인하고 설치 대상 디스크와 파티션을 선택합니다. 파티션 삭제·포맷은 그 안의 데이터를 삭제합니다.
  3. 새 설치가 필요하고 백업이 완료된 경우에만 올바른 파티션을 선택해 파일 시스템과 포맷 옵션을 진행합니다.
  4. 설치 프로그램의 파일 복사와 재부팅을 기다린 뒤 지역 설정, 이름, 제품 키, 시간대, 네트워크 설정 등을 입력합니다.
  5. 설치 중 디스크가 표시되지 않으면 저장장치 컨트롤러 드라이버 또는 BIOS의 저장장치 설정 호환성을 확인합니다. 임의로 BIOS 설정을 바꾸기 전 기존 OS가 해당 설정을 지원하는지 확인하세요.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. PC 제조사에서 제공한 호환 칩셋·그래픽·오디오·네트워크 드라이버를 설치합니다.
  2. 장치 관리자에서 드라이버 상태를 확인하고 필요한 레거시 프로그램을 설치합니다.
  3. 네트워크 연결을 끄거나 격리하고, 현대적인 웹 브라우징이나 민감한 작업에 사용하지 않습니다.

6. 문제 해결 체크리스트

  1. 설치 디스크가 안 보이면 SATA/AHCI 드라이버와 저장장치 호환성을 확인합니다.
  2. USB로 부팅되지 않으면 정품 CD/DVD 설치를 검토하고 PC의 USB 부팅 지원을 확인합니다.
  3. 설치 후 해상도나 사운드가 맞지 않으면 장치 모델과 XP 지원 여부를 확인합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
