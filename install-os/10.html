Windows 10 설치 안내

초급 · 호환성 확인 권장

Windows 10 설치 전 PC 사양, 데이터 백업, 공식 설치 매체를 준비하세요.

설치 전 주의사항
Windows 10 일반 지원은 2025년 10월 14일 종료되었습니다. 일부 기기·프로그램에 대한 별도 지원 여부를 확인하고, 가능하면 지원되는 운영체제로 전환하세요.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. 설정 또는 제조사 안내에서 CPU, 메모리, 저장 공간, 64비트 지원 여부를 확인합니다.
  2. 사진·문서·브라우저 데이터와 복구 키를 백업합니다. BitLocker 사용 시 복구 키를 별도로 보관하세요.
  3. Microsoft 공식 Windows 10 다운로드 페이지에서 Media Creation Tool 또는 안내된 설치 ISO를 이용합니다.
  4. 빈 USB 드라이브(일반적으로 8GB 이상)를 준비하고 공식 도구로 설치 USB를 만듭니다. USB 안의 파일은 삭제됩니다.
  5. USB로 부팅해 설치를 시작하고 에디션과 설치 대상 디스크를 확인합니다. 데이터 보존이 목적이면 설치 유형을 신중히 선택하세요.
  6. 설치 후 Windows Update, 제조사 드라이버, 장치 관리자 상태를 확인하고 활성화 상태를 점검합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.

공식 자료

설치 이미지와 최신 지침은 운영체제 공급자의 공식 웹사이트에서 확인하세요.
