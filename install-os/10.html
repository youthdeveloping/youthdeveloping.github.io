Windows 10 설치 방법

초급 · 설치 미디어 만들기 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows 10은 공식 설치 USB를 만들고 USB에서 부팅해 새로 설치하거나 재설치할 수 있습니다.

설치 전 반드시 읽어 주세요
Windows 10 일반 지원은 2025년 10월 14일 종료되었습니다. 가능한 경우 지원되는 Windows 버전으로 전환하고, 적용 가능한 연장 보안 업데이트가 있는지 확인하세요.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. Microsoft 공식 Windows 10 다운로드 페이지를 엽니다.
  2. '설치 미디어 만들기' 도구를 내려받아 실행합니다. 도구가 실행되지 않으면 시스템 요구 사항과 관리자 권한을 확인합니다.
  3. 사용 조건에 동의하고 '다른 PC용 설치 미디어 만들기'를 선택합니다.
  4. 언어, 에디션, 아키텍처를 확인합니다. 다른 PC에 설치할 경우 해당 PC와 일치하는 옵션을 선택합니다.
  5. 'USB 플래시 드라이브'를 선택하고 최소 8GB의 빈 USB를 연결합니다. USB 안의 모든 파일이 삭제됩니다.
  6. 목록에서 USB 이름과 용량을 확인하고 다음을 누릅니다. 제작이 끝날 때까지 USB를 분리하지 않습니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Windows 10 다운로드

3. USB/DVD로 부팅하기

  1. 설치 대상 PC에 USB를 연결하고 완전히 종료한 뒤 전원을 켭니다.
  2. 제조사 로고가 표시될 때 부팅 메뉴 키를 반복해서 누릅니다. 흔히 F12, F9, Esc 등이지만 모델 설명서를 확인하세요.
  3. 목록에서 USB 또는 UEFI USB 항목을 선택합니다. USB가 표시되지 않으면 포트나 제작 상태를 확인합니다.
  4. Windows Setup이 시작되면 언어, 시간·통화 형식, 키보드를 선택하고 다음을 누릅니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. '지금 설치'를 누릅니다. 제품 키를 물으면 보유한 라이선스에 맞게 입력하거나 화면의 '제품 키가 없음' 옵션이 허용되는 경우 나중에 활성화합니다.
  2. 설치할 Windows 에디션을 선택할 때 보유한 라이선스와 일치하는지 확인합니다.
  3. 설치 유형에서 기존 설치를 유지하는 업그레이드와 새로 설치하는 사용자 지정의 차이를 확인합니다. USB로 부팅한 클린 설치는 기존 앱과 설정을 보존하지 못할 수 있습니다.
  4. 디스크 목록에서 설치 대상 드라이브를 용량으로 구분합니다. 파티션 삭제·포맷은 데이터를 삭제합니다. 데이터 보존이 필요하거나 어떤 파티션인지 불확실하면 중단합니다.
  5. 대상 파티션을 선택하고 다음을 눌러 파일 복사를 시작합니다. 여러 번 재부팅될 수 있으며 설치가 진행되는 동안 전원을 끄지 않습니다.
  6. 초기 설정에서 지역, 키보드, 네트워크, 계정 및 개인정보 설정을 완료합니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 바탕 화면이 열리면 설정의 Windows Update에서 적용 가능한 업데이트를 확인합니다.
  2. PC 제조사 공식 지원 페이지에서 칩셋, 네트워크, 오디오, 그래픽 드라이버를 확인합니다.
  3. 장치 관리자에 알 수 없는 장치나 오류 표시가 없는지 확인합니다.
  4. 설정에서 활성화 상태를 확인하고 필요한 경우 정품 라이선스 문제를 해결합니다.
  5. 파일 백업을 복원하고 복구 드라이브를 만드는 것을 고려합니다.

6. 문제 해결 체크리스트

  1. USB가 부팅되지 않으면 USB 제작을 다시 수행하고 다른 포트와 부팅 메뉴 항목을 확인합니다.
  2. 설치 디스크가 보이지 않으면 제조사 저장장치 드라이버 또는 컨트롤러 호환성을 확인합니다.
  3. 인터넷이 안 되면 다른 기기에서 제조사의 공식 네트워크 드라이버를 받아 옮깁니다.
  4. 설치 후 이전 OS로 돌아가야 한다면 추가 포맷이나 설치를 하지 말고 백업 및 복구 옵션을 먼저 확인합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
