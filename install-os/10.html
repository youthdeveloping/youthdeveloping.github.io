Windows 10 설치 방법

Windows · 설치 준비부터 설치 후 점검까지

Microsoft 미디어 생성 도구를 사용해 USB를 만들고 설치하는 절차입니다.

시작하기 전에
일반 지원은 2025년 10월 14일 종료되었습니다. 지원되는 버전으로 전환하거나 적용 가능한 연장 보안 업데이트를 확인하세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. Microsoft 공식 Windows 10 다운로드 페이지를 엽니다.
  2. Media Creation Tool을 내려받아 실행하고 사용 조건에 동의합니다.
  3. '다른 PC용 설치 미디어 만들기'를 선택하고 언어·에디션·아키텍처를 확인합니다.
  4. 'USB 플래시 드라이브'를 선택하고 8GB 이상 빈 USB를 연결합니다.
  5. 목록에서 USB 이름과 용량을 확인한 뒤 제작을 시작합니다. USB 데이터는 모두 삭제됩니다.
  6. 완료 메시지가 나올 때까지 USB를 분리하지 않습니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Windows 10 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. USB를 설치 대상 PC에 꽂고 완전히 종료합니다.
  2. 전원을 켜며 부팅 메뉴 키(F12/F9/Esc 등 모델별 상이)를 누릅니다.
  3. USB 또는 UEFI USB 항목을 선택합니다.
  4. 언어·시간·키보드를 선택하고 다음을 누릅니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. '지금 설치'를 누릅니다.
  2. 제품 키를 입력하거나 화면에서 허용하는 경우 나중에 입력합니다. 보유한 라이선스와 같은 에디션을 선택합니다.
  3. 설치 유형에서 업그레이드와 사용자 지정의 차이를 확인합니다. USB 부팅 클린 설치는 앱과 설정을 유지하지 못할 수 있습니다.
  4. 대상 디스크를 용량으로 구분합니다. 파티션 삭제·포맷은 데이터를 삭제하므로 불확실하면 중단합니다.
  5. 파일 복사와 여러 차례 재부팅이 끝날 때까지 전원을 끄지 않습니다.
  6. 지역, 키보드, 네트워크, 계정과 개인정보 설정을 완료합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. Windows Update에서 적용 가능한 업데이트를 확인합니다.
  2. 제조사 공식 페이지에서 칩셋·네트워크·오디오·그래픽 드라이버를 확인합니다.
  3. 장치 관리자와 활성화 상태를 점검하고 백업을 복원합니다.

6. 문제 해결

  1. USB 부팅 실패는 제작 도구·포트·부팅 메뉴를 확인합니다.
  2. 디스크 미표시는 제조사 스토리지 드라이버를 확인합니다.
  3. 인터넷이 안 되면 다른 기기에서 공식 네트워크 드라이버를 받아 옮깁니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
