Windows 8 설치 방법

중급 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows 8 설치는 구형 프로그램 호환성 등의 특별한 목적을 위한 안내입니다.

설치 전 반드시 읽어 주세요
Windows 8 지원은 종료되었습니다. Windows 8.1은 별도 버전이며 지원 종료 상태입니다.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. PC의 32/64비트 아키텍처, UEFI/BIOS 모드와 드라이버 지원을 확인합니다.
  2. 백업, 정품 설치 매체 및 해당 에디션에 맞는 제품 키를 준비합니다.
  3. 빈 USB를 사용해 호환 도구로 부팅 매체를 만들거나 정품 DVD를 준비합니다. USB 제작 과정에서 기존 데이터가 삭제됩니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. USB/DVD를 연결하고 PC를 재시작합니다.
  2. 부팅 메뉴에서 설치 장치를 선택합니다. UEFI 장치라면 UEFI 항목을 선택합니다.
  3. 설치 화면에서 언어와 키보드를 선택합니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 시작을 누르고 라이선스 조건을 확인합니다.
  2. 설치 유형을 선택하고 대상 디스크와 파티션을 재확인합니다.
  3. 기존 파일을 유지해야 한다면 포맷이나 파티션 삭제를 진행하지 않습니다.
  4. 화면의 안내에 따라 설치를 완료하고 사용자 계정 및 기본 설정을 구성합니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 제조사 드라이버와 필요한 업데이트를 확인합니다.
  2. 앱 설치 전에 설치 파일의 출처를 확인합니다.
  3. 지원 종료로 인한 위험을 고려해 온라인 사용을 피합니다.

6. 문제 해결 체크리스트

  1. 부팅 실패 시 설치 매체와 UEFI/Legacy 방식의 호환성을 확인합니다.
  2. 디스크가 안 보이면 저장장치 드라이버 지원을 확인합니다.
  3. 제품 키 오류 시 설치 에디션과 보유 라이선스가 일치하는지 확인합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
