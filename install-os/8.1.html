Windows 8.1 설치 방법

중급 · 지원 종료 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows 8.1은 Windows 8과 구분되는 버전이며 설치 매체와 라이선스 에디션을 확인해야 합니다.

설치 전 반드시 읽어 주세요
Windows 8.1 지원은 2023년 1월 10일 종료되었습니다. 인터넷에 연결된 주 운영체제로 권장하지 않습니다.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. PC 모델, 아키텍처, UEFI/BIOS 모드와 드라이버 호환성을 확인합니다.
  2. 중요한 파일을 백업하고 정품 Windows 8.1 설치 매체와 해당 버전의 제품 키를 준비합니다.
  3. 호환 USB 제작 도구 또는 DVD를 준비합니다. USB 제작 전에 안의 파일을 별도 저장합니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. USB/DVD를 연결하고 PC를 재시작합니다.
  2. 제조사 부팅 메뉴를 열어 해당 매체를 선택합니다.
  3. 설치 화면에서 언어와 키보드를 확인합니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 프로그램의 지시에 따라 시작하고 라이선스 조건을 확인합니다.
  2. 설치 유형을 선택합니다. 새로 설치라면 사용자 지정 설치를 선택하되, 파티션 삭제 전 백업을 확인합니다.
  3. 정확한 대상 디스크를 선택하고 설치를 진행합니다.
  4. 재부팅 후 사용자 계정, 시간대, 네트워크 등 초기 설정을 완료합니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 호환 드라이버를 설치하고 장치 관리자에서 상태를 확인합니다.
  2. 필요한 레거시 앱을 신뢰할 수 있는 출처에서 설치합니다.
  3. 지원 종료에 따른 보안 위험 때문에 인터넷 연결을 피합니다.

6. 문제 해결 체크리스트

  1. 부팅 장치가 안 보이면 UEFI 설정과 설치 매체 제작 방식을 확인합니다.
  2. 디스크가 안 보이면 저장장치 드라이버를 확인합니다.
  3. 설치 키가 거부되면 버전·에디션·라이선스 일치 여부를 확인합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
