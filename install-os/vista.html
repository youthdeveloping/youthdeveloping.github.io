Windows Vista 설치 방법

중급 · 레거시 PC · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Vista는 호환되는 구형 PC에서만 설치를 권장합니다.

설치 전 반드시 읽어 주세요
지원 종료 운영체제입니다. 일상적인 인터넷 접속에 사용하지 말고 정품 설치 매체를 사용하세요.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. PC 모델과 Vista 드라이버 지원 여부를 확인합니다.
  2. 개인 파일을 백업하고 정품 설치 DVD/ISO와 라이선스를 준비합니다.
  3. DVD로 설치하거나, USB 설치가 필요하면 해당 PC의 부팅 지원과 설치 이미지의 호환성을 확인합니다. ISO를 USB에 단순 복사하는 것만으로는 부팅 디스크가 되지 않습니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. PC를 켜고 BIOS 또는 일회성 Boot Menu를 엽니다.
  2. DVD 또는 호환 USB 장치를 선택해 설치 프로그램을 시작합니다.
  3. 설치 프로그램이 열리지 않으면 부팅 순서와 설치 매체의 상태를 확인합니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 언어·시간·키보드 설정을 확인하고 설치를 시작합니다.
  2. 라이선스 조건과 설치 유형을 확인합니다.
  3. 대상 디스크와 파티션을 다시 확인합니다. 포맷 또는 삭제는 기존 데이터를 지웁니다.
  4. 화면의 안내에 따라 파일 복사와 재부팅을 완료하고 사용자·제품 키·시간대 정보를 입력합니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 호환 칩셋, 그래픽, 사운드, 네트워크 드라이버를 설치합니다.
  2. 장치 관리자에서 오류가 있는 장치를 확인합니다.
  3. 백업을 복원하고 인터넷 연결을 피합니다.

6. 문제 해결 체크리스트

  1. 디스크가 표시되지 않으면 저장장치 드라이버와 컨트롤러 호환성을 확인합니다.
  2. USB가 부팅되지 않으면 DVD 설치나 다른 호환 매체를 검토합니다.
  3. 드라이버는 정확한 PC 모델과 OS 버전에 맞는지 확인합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
