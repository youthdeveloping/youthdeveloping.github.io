Windows Vista 설치 안내

중급 · 레거시 환경

Windows Vista 설치는 당시 하드웨어와 호환되는 PC에서 진행해야 합니다.

설치 전 주의사항
Windows Vista 지원은 종료되었습니다. 인터넷 연결을 피하고, 주 운영체제로 사용하지 마세요.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. PC 사양과 Vista용 칩셋·저장장치·그래픽 드라이버를 확인합니다.
  2. 중요한 파일을 백업하고 정품 Vista 설치 DVD와 필요한 제품 키를 준비합니다.
  3. BIOS 또는 부팅 메뉴에서 DVD/호환 설치 매체를 선택합니다.
  4. 설치 화면에서 사용자 지정 설치를 선택하고 대상 디스크와 파티션을 신중히 확인합니다. 포맷하면 데이터가 삭제됩니다.
  5. 설치가 끝나면 제조사가 제공한 호환 드라이버를 설치합니다.
  6. 지원 종료로 인한 위험을 고려해 오프라인 또는 격리된 환경에서 사용합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.

설치 이미지와 최신 지침은 운영체제 공급자의 공식 웹사이트에서 확인하세요.
