Windows Server 2022 설치 방법

서버 · 설치 준비부터 설치 후 점검까지

Windows Server 설치는 역할 구성과 네트워크 보안 계획까지 필요합니다.

시작하기 전에
서버는 데이터와 네트워크에 영향을 줄 수 있습니다. 백업·복구 계획 없이 실제 서버에 설치하지 마세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. 공식 ISO와 라이선스/평가판 안내, 하드웨어 요구 사항을 확인합니다.
  2. 스토리지, NIC, 서버 이름, 고정 IP, 도메인 요구 사항과 복구 계획을 준비합니다.
  3. 빈 USB에 공식 이미지 기반 설치 미디어를 만듭니다. USB 데이터는 삭제됩니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Windows Server 2022 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. 서버를 재부팅하고 부팅 메뉴에서 USB 또는 가상 미디어를 선택합니다.
  2. UEFI 설정과 스토리지 컨트롤러 호환성을 확인합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 라이선스에 맞는 에디션을 선택합니다.
  2. Server Core와 Desktop Experience의 차이를 확인하고 필요한 설치 옵션을 선택합니다.
  3. 대상 디스크를 확인하고 파티션을 구성합니다.
  4. 설치 후 관리자 암호, 서버 이름, 시간대와 네트워크를 설정합니다.
  5. 필요한 역할과 기능만 최소한으로 추가합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 업데이트와 제조사 드라이버를 적용합니다.
  2. 방화벽, 원격 관리, 권한, 로그, 백업 및 복구를 구성합니다.
  3. 불필요한 서비스를 끄고 관리 인터페이스를 인터넷에 직접 노출하지 않습니다.

6. 문제 해결

  1. 스토리지 미표시는 RAID/스토리지 드라이버를 확인합니다.
  2. 네트워크 연결은 NIC 드라이버와 IP/VLAN 구성을 점검합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
