Windows 11 설치 안내

초급 · 공식 요구 사항 확인

Windows 11은 지원되는 PC에서 공식 설치 도구를 이용하는 방법을 권장합니다.

설치 전 주의사항
최소 요구 사항을 우회해 설치하면 업데이트와 지원이 보장되지 않을 수 있습니다. 업무용·주 사용 PC는 호환성 우회를 피하세요.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. PC 상태 검사 앱 또는 Microsoft 공식 요구 사항 페이지에서 호환 CPU, TPM 2.0, Secure Boot, 메모리와 저장 공간을 확인합니다.
  2. 개인 파일을 백업하고 BitLocker 복구 키를 보관합니다.
  3. Microsoft 공식 Windows 11 다운로드 페이지에서 설치 도우미 또는 미디어 생성 도구를 선택합니다.
  4. USB 설치 미디어를 만들 경우 일반적으로 8GB 이상인 빈 USB를 사용합니다. 제작 과정에서 USB 데이터가 삭제됩니다.
  5. 설치 USB로 부팅하거나 설치 도우미를 실행하고, 안내에 따라 설치를 진행합니다. 새로 설치할 경우 대상 디스크를 반드시 확인하세요.
  6. 설치 후 Windows Update, 제조사 드라이버, 활성화 상태 및 장치 관리자를 확인합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.
