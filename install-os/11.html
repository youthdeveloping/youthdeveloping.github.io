Windows 11 설치 방법

Windows · 설치 준비부터 설치 후 점검까지

공식 Windows 11 미디어 생성 도구로 USB를 만들고 설치합니다.

시작하기 전에
지원 CPU, TPM 2.0, Secure Boot 등 요구 사항을 확인하세요. 요구 사항 우회는 지원을 보장하지 않습니다.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. PC 상태 검사 또는 Microsoft 요구 사항 페이지에서 호환성을 확인합니다.
  2. 중요 파일과 BitLocker 복구 키를 백업합니다.
  3. Microsoft Windows 11 다운로드 페이지에서 미디어 생성 도구를 내려받아 실행합니다.
  4. 사용 조건에 동의하고 언어·에디션을 확인합니다.
  5. USB 플래시 드라이브를 선택하고 8GB 이상 빈 USB를 연결합니다.
  6. 대상 USB 이름·용량을 확인하고 제작을 시작합니다. USB 안의 데이터는 삭제됩니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Windows 11 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. USB를 대상 PC에 연결하고 재시작합니다.
  2. 부팅 메뉴 키를 눌러 UEFI USB를 선택합니다.
  3. Windows Setup에서 언어와 키보드를 확인합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. '지금 설치'를 선택합니다.
  2. 제품 키와 에디션은 라이선스에 맞게 선택합니다.
  3. 새 설치라면 사용자 지정 설치를 선택하되 대상 디스크를 용량으로 확인합니다.
  4. 파티션 삭제·포맷은 데이터를 지우므로 백업이 확인되지 않았다면 진행하지 않습니다.
  5. 파일 복사와 재부팅 후 지역·네트워크·계정 설정을 완료합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. Windows Update와 제조사 드라이버를 설치합니다.
  2. 활성화 상태, 장치 관리자, 복구 키 보관 상태를 확인합니다.
  3. 복구 드라이브와 정기 백업을 고려합니다.

6. 문제 해결

  1. USB가 목록에 없으면 부팅 메뉴와 USB 제작 상태를 확인합니다.
  2. TPM/Secure Boot 경고는 PC 요구 사항을 확인합니다.
  3. 디스크가 보이지 않으면 제조사 저장장치 드라이버를 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
