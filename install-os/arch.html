Arch Linux 설치 방법

Linux · 설치 준비부터 설치 후 점검까지

Arch Linux는 파티션, 부트로더와 시스템을 직접 구성하는 고급 사용자용 OS입니다.

시작하기 전에
잘못된 디스크 명령은 데이터를 즉시 지울 수 있습니다. 초보자는 가상 머신에서 먼저 연습하세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. 공식 ISO를 다운로드하고 서명/체크섬을 확인합니다.
  2. 이미지 작성 도구로 USB를 만듭니다.
  3. 디스크, 네트워크, UEFI 방식과 백업을 확인합니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Arch Linux 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. USB로 부팅해 설치 환경을 시작합니다.
  2. 네트워크 연결과 키보드를 확인합니다.
  3. 공식 Installation Guide를 열어 현재 지침을 따릅니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 디스크 식별 후 파티션, 파일 시스템과 마운트 지점을 구성합니다. 장치 이름을 여러 번 확인합니다.
  2. 기본 시스템을 설치하고 시스템 설정을 생성합니다.
  3. 부트로더, 시간대, 로케일, 사용자와 네트워크를 구성합니다.
  4. 필요하면 데스크톱 환경을 별도로 설치하고 재부팅합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 패키지 관리자로 시스템을 갱신합니다.
  2. 백업과 복구 절차를 준비합니다.

6. 문제 해결

  1. 부팅 실패 시 UEFI 부트 항목과 부트로더를 공식 가이드대로 점검합니다.
  2. 네트워크 설정은 설치 환경과 설치된 시스템을 구분해 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
