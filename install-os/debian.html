Debian 설치 방법

Linux · 설치 준비부터 설치 후 점검까지

Debian은 설치 프로그램에서 파티션과 데스크톱 환경을 선택할 수 있습니다.

시작하기 전에
파티션 변경은 데이터를 삭제할 수 있습니다. 무선 네트워크 장치에 추가 펌웨어가 필요할 수 있습니다.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. debian.org/distrib에서 PC 아키텍처에 맞는 안정판 이미지를 다운로드합니다.
  2. 가능하면 공식 체크섬 검증 지침을 따릅니다.
  3. Rufus/Etcher 등 도구에서 ISO와 USB를 선택해 기록합니다. USB 데이터는 삭제됩니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Debian 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. USB로 부팅해 Graphical Install 또는 Install을 선택합니다.
  2. 언어, 위치, 키보드 배열을 설정합니다.
  3. 네트워크 장치가 감지되는지 확인합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 호스트 이름과 사용자 계정을 설정합니다.
  2. 파티션 방법을 선택합니다. 자동 파티션도 대상 디스크를 덮어쓸 수 있으므로 디스크를 재확인합니다.
  3. 설치할 데스크톱 환경과 시스템 유틸리티를 선택합니다.
  4. 부트로더 설치 대상이 올바른 디스크인지 확인합니다.
  5. 설치를 마치고 재부팅합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 패키지 목록을 갱신하고 보안 업데이트를 적용합니다.
  2. 네트워크·오디오·그래픽·펌웨어를 확인합니다.
  3. 백업과 복구 절차를 준비합니다.

6. 문제 해결

  1. 부팅 실패 시 설치 매체와 부트로더 설정을 확인합니다.
  2. Wi‑Fi가 안 되면 공식 펌웨어 안내를 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
