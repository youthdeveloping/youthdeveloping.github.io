Debian Linux 설치 안내

중급 · 설치 옵션 확인

Debian은 안정성과 다양한 설치 구성을 제공하는 Linux 배포판입니다.

설치 전 주의사항
설치 과정에서 디스크 파티션을 잘못 선택하면 데이터가 삭제됩니다. 중요한 파일을 먼저 백업하세요. 펌웨어가 필요한 Wi‑Fi 등은 기기에 따라 추가 설정이 필요할 수 있습니다.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. Debian 공식 사이트에서 PC 아키텍처에 맞는 안정판 설치 이미지를 선택합니다. 초보자는 설치 안내가 포함된 공식 이미지를 권장합니다.
  2. 공식 지침에 따라 이미지의 체크섬을 확인하고 부팅 USB를 만듭니다. USB 데이터는 삭제될 수 있습니다.
  3. USB로 부팅한 뒤 그래픽 설치 또는 일반 설치를 선택하고 언어, 위치, 키보드를 설정합니다.
  4. 네트워크와 사용자 계정을 설정합니다. 설치 중 필요한 펌웨어가 있는지 장치 호환성을 확인합니다.
  5. 파티션 구성 화면에서 자동 또는 수동 방식을 신중히 선택합니다. 디스크 전체 사용은 기존 데이터를 지울 수 있습니다.
  6. 설치할 데스크톱 환경과 시스템 도구를 선택하고 설치를 마친 뒤 재부팅합니다.
  7. 부팅 후 패키지 목록을 갱신하고 보안 업데이트를 적용한 다음 필요한 드라이버와 프로그램을 설정합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.
