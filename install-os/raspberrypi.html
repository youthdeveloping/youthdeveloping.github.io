Raspberry Pi OS 설치 방법

기타 · 설치 준비부터 설치 후 점검까지

Raspberry Pi OS는 Raspberry Pi 보드용 공식 운영체제이며 microSD 카드에 기록합니다.

시작하기 전에
이미지 기록은 microSD 카드의 데이터를 삭제합니다. 일반 PC용 x86 OS와 ARM 보드용 이미지는 다릅니다.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. Raspberry Pi 모델, 호환 전원 어댑터, microSD 카드와 카드 리더기를 준비합니다.
  2. PC에 Raspberry Pi Imager를 설치합니다.
  3. Imager에서 보드 모델, Raspberry Pi OS 버전, 저장장치를 선택합니다.
  4. 선택적 설정에서 사용자·암호·Wi‑Fi를 지정할 수 있습니다. 공용 기기에는 비밀번호를 저장하지 마세요.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Raspberry Pi OS 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. 쓰기 전에 선택된 저장장치의 이름과 용량을 재확인합니다.
  2. OS 이미지를 기록하고 검증이 끝날 때까지 기다립니다.
  3. 카드를 안전하게 꺼내 Raspberry Pi 슬롯에 넣고 모니터·키보드를 연결합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 전원을 켜고 초기 설정에서 국가, 언어, 시간대와 네트워크를 지정합니다.
  2. 계정을 확인하고 업데이트를 적용합니다.
  3. 헤드리스 사용 시 원격 접속과 네트워크 보안을 별도로 설정합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 패키지를 갱신하고 중요한 파일을 별도 위치에 백업합니다.
  2. 전원 공급과 저장장치 상태를 확인합니다.

6. 문제 해결

  1. 부팅되지 않으면 카드 기록 검증, 전원 어댑터와 보드 모델을 확인합니다.
  2. 화면이 안 나오면 HDMI 포트와 케이블을 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
