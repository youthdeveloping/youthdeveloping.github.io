Ubuntu 설치 방법

Linux · 설치 준비부터 설치 후 점검까지

Ubuntu는 라이브 USB로 먼저 시험한 뒤 설치할 수 있습니다.

시작하기 전에
디스크 전체 사용은 기존 파일을 지울 수 있습니다. Windows 듀얼 부팅 시 BitLocker 복구 키와 백업을 먼저 확인하세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. ubuntu.com/download에서 Desktop ISO를 다운로드합니다.
  2. 공식 안내에 맞춰 Rufus 등 이미지 작성 도구에서 ISO와 USB를 선택합니다.
  3. 최소 8GB 권장 USB를 선택하고 기록합니다. USB 데이터는 삭제됩니다.
  4. 가능하면 다운로드한 이미지의 무결성을 공식 안내대로 확인합니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Ubuntu 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. USB를 연결하고 재부팅한 뒤 부팅 메뉴(F12/Esc/F2/F10 등)를 엽니다.
  2. USB 장치를 선택합니다.
  3. Try Ubuntu로 라이브 데스크톱을 실행해 Wi‑Fi, 소리, 화면, 터치패드를 시험합니다.
  4. 설치를 결정하면 Install Ubuntu를 실행합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 언어, 접근성, 키보드 배열과 네트워크를 설정합니다.
  2. 기본 또는 확장 앱 구성을 선택합니다.
  3. 필요한 경우 타사 드라이버·미디어 형식 지원 옵션을 선택합니다.
  4. 설치 유형을 선택합니다. '디스크 지우기'는 해당 디스크 전체를 사용하므로 기존 OS와 파일을 삭제할 수 있습니다.
  5. 듀얼 부팅은 여유 공간, BitLocker, 파티션을 확인합니다. 수동 파티션은 고급 사용자용입니다.
  6. 시간대, 사용자 이름, 컴퓨터 이름과 강력한 암호를 설정합니다.
  7. 설치 요약을 확인하고 설치를 시작합니다. 완료 후 재부팅하며 안내가 나오면 USB를 제거합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. Software Updater 또는 공식 패키지 도구로 업데이트합니다.
  2. 추가 드라이버와 장치 작동을 확인합니다.
  3. 암호화 키를 설정했다면 안전한 별도 위치에 보관합니다.

6. 문제 해결

  1. USB 부팅 실패는 ISO 기록 상태와 부팅 메뉴를 확인합니다.
  2. Intel RST 등 저장장치 설정이 설치를 막을 수 있으므로 공식 Ubuntu 안내를 확인합니다.
  3. Wi‑Fi가 안 되면 장치 펌웨어와 호환성을 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
