Proxmox VE 설치 방법

서버 · 설치 준비부터 설치 후 점검까지

Proxmox VE는 가상 머신과 컨테이너를 관리하는 가상화 서버 플랫폼입니다.

시작하기 전에
설치 디스크가 초기화될 수 있습니다. 백업, 네트워크 주소와 복구 계획을 준비하세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. 공식 ISO를 다운로드합니다.
  2. CPU 가상화, RAM, 저장장치와 네트워크 어댑터 호환성을 확인합니다.
  3. USB 이미지 작성 도구로 설치 USB를 만듭니다. USB 데이터는 삭제됩니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Proxmox VE 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. 서버를 재부팅하고 USB로 부팅합니다.
  2. 설치 프로그램의 라이선스 안내를 확인합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 대상 디스크를 선택합니다. 선택한 디스크가 지워질 수 있으므로 정확히 구분합니다.
  2. 국가·시간대·키보드, 관리자 암호와 이메일을 입력합니다.
  3. 관리 네트워크의 호스트 이름, IP, 게이트웨이와 DNS를 정확히 설정합니다.
  4. 요약을 확인하고 설치 후 재부팅합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 같은 네트워크의 다른 PC에서 화면에 표시된 관리 주소로 접속합니다.
  2. 공식 업데이트를 적용하고 저장소·백업·복구 정책을 구성합니다.
  3. 관리 화면을 인터넷에 직접 노출하지 말고 신뢰된 네트워크/VPN을 사용합니다.

6. 문제 해결

  1. 웹 관리 화면에 접속되지 않으면 IP, 케이블, VLAN, 게이트웨이를 확인합니다.
  2. 디스크 미표시는 컨트롤러 호환성을 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
