Windows 7 설치 방법

중급 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows 7은 지원 종료 상태입니다. 설치 전에 드라이버와 보안 위험을 확인하세요.

설치 전 반드시 읽어 주세요
Windows 7 지원이 종료되었습니다. 일반 웹 접속과 민감한 업무용 사용은 권장하지 않습니다.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. PC의 32/64비트 지원, BIOS/UEFI 방식, USB 3.x 및 저장장치 드라이버 호환성을 확인합니다.
  2. 중요 파일과 복구 키를 백업하고 정품 설치 DVD 또는 ISO와 제품 키를 준비합니다.
  3. 설치 USB를 만들 경우 신뢰할 수 있는 이미지 작성 도구에서 ISO와 USB 장치를 선택합니다. USB의 데이터가 모두 지워집니다.
  4. 현대 PC의 USB 3.x/NVMe 장치에는 Windows 7 설치 이미지에 없는 드라이버가 필요할 수 있습니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. USB/DVD를 연결한 상태에서 PC를 재시작합니다.
  2. 부팅 메뉴 키를 눌러 'UEFI: USB' 또는 해당 설치 매체를 선택합니다. 설치 방식과 부팅 방식은 일치해야 합니다.
  3. 설치 화면이 나타나면 언어와 키보드를 확인합니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치를 시작하고 라이선스 조건을 확인합니다.
  2. 업그레이드 또는 사용자 지정 설치 중 목적에 맞는 항목을 선택합니다. 새로 설치는 사용자 지정이 일반적입니다.
  3. 대상 디스크·파티션을 확인합니다. 삭제·포맷은 데이터를 지우므로 백업이 확인되지 않았다면 중단합니다.
  4. 설치 후 사용자 이름, 컴퓨터 이름, 시간대 및 라이선스 정보를 입력합니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 제조사에서 제공하는 Windows 7용 드라이버를 설치하고 장치 관리자를 확인합니다.
  2. Windows Update 및 설치된 보안 소프트웨어의 상태를 확인하되, 지원 종료로 인해 보호가 충분하지 않다는 점을 기억합니다.
  3. 가능하면 오프라인 또는 격리 환경에서 레거시 앱을 실행합니다.

6. 문제 해결 체크리스트

  1. USB 부팅이 되지 않으면 UEFI/Legacy 설정과 제작 도구의 부팅 방식 설정을 확인합니다.
  2. 설치 프로그램에서 디스크가 보이지 않으면 제조사의 저장장치 드라이버를 확인합니다.
  3. 키보드·마우스가 설치 화면에서 작동하지 않으면 USB 2.0 포트 등 기기 호환성을 점검합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
