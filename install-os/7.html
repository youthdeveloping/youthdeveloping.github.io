Windows 7 설치 안내

중급

Windows 7은 지원 종료 운영체제입니다. 설치 전에 PC와 드라이버 호환성을 확인하세요.

설치 전 주의사항
Windows 7의 일반 지원은 종료되었습니다. 웹 접속이나 민감한 작업에 사용하는 것은 권장하지 않습니다.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. PC 제조사의 사양과 Windows 7 드라이버 지원 여부를 확인합니다. 최신 PC에서는 USB 3.x, NVMe, UEFI 호환 문제가 발생할 수 있습니다.
  2. 개인 파일과 복구 파티션을 백업하고 정품 설치 매체 및 제품 키를 준비합니다.
  3. 공식적으로 신뢰할 수 있는 설치 매체를 사용해 부팅 USB/DVD를 준비합니다. USB 제작 시 해당 매체의 모든 데이터가 지워질 수 있습니다.
  4. 부팅 메뉴에서 설치 매체를 선택하고 설치 프로그램을 시작합니다.
  5. 설치 유형과 대상 파티션을 확인합니다. 기존 시스템을 덮어쓰거나 포맷하기 전에 백업을 확인하세요.
  6. 설치 후 제조사 드라이버를 설치하고, 지원 종료 위험을 감안해 오프라인 또는 격리 환경에서 사용합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.

공식 자료

설치 이미지와 최신 지침은 운영체제 공급자의 공식 웹사이트에서 확인하세요.
