Windows 7 설치 방법

Windows · 설치 준비부터 설치 후 점검까지

드라이버와 부팅 방식 호환성을 확인하고 설치하세요.

시작하기 전에
지원 종료 OS입니다. 일상적인 웹 접속에는 권장하지 않습니다.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. PC의 32/64비트, UEFI/Legacy, USB 3.x와 저장장치 호환성을 확인합니다.
  2. 백업, 정품 설치 DVD/ISO, 제품 키를 준비합니다.
  3. 이미지 작성 도구에서 ISO와 빈 USB를 선택해 부팅 USB를 만듭니다. USB 데이터는 삭제됩니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Windows 7 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. 재부팅 후 제조사 부팅 메뉴를 열고 USB/DVD를 선택합니다.
  2. UEFI로 설치할 경우 UEFI USB 항목을 선택합니다.
  3. 설치 화면에서 언어와 키보드를 선택합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 라이선스 조건을 확인하고 설치 유형을 선택합니다.
  2. 새 설치는 보통 사용자 지정 설치를 사용하지만 파티션 삭제 전에 백업을 확인합니다.
  3. 대상 디스크를 용량으로 식별하고 설치를 진행합니다.
  4. 초기 사용자·시간대 설정을 마칩니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 호환 드라이버를 설치하고 장치 관리자 상태를 확인합니다.
  2. 지원 종료 위험을 고려해 오프라인/격리 환경에서 사용합니다.

6. 문제 해결

  1. USB 입력장치가 작동하지 않으면 USB 2.0 포트 등 호환성을 확인합니다.
  2. 디스크 미표시는 저장장치 드라이버를 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
