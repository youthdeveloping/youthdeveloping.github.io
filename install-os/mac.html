macOS 설치 방법

Mac 전용 · USB 제작부터 설치 후 설정까지

macOS는 호환되는 Apple Mac에서 Apple 공식 설치·복구 절차로 설치하세요.

중요한 주의사항
일반 PC에 macOS를 설치하는 비공식 방법은 이 안내의 대상이 아닙니다. 디스크 지우기는 데이터를 삭제하므로 백업부터 진행하세요.

1. 설치 전 준비

  1. 설치할 컴퓨터의 모델, CPU 아키텍처, 메모리, 저장 공간과 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 사진·문서 등 중요한 파일을 외장 드라이브나 클라우드에 백업합니다. 암호화된 디스크라면 복구 키도 별도로 보관합니다.
  3. 가능하면 안정적인 전원에 연결하고, 설치에 사용할 빈 USB를 준비합니다. Windows 설치 미디어는 보통 8GB 이상을 권장하며, Linux/macOS도 해당 공식 안내의 용량을 따릅니다.
  4. 설치 이미지와 제품 키가 필요한 경우 운영체제 공급자의 공식 출처에서 준비합니다. 라이선스가 없는 운영체제 복제본이나 출처가 불분명한 ISO는 사용하지 마세요.

2. USB 설치 디스크 만들기

  1. 공식 다운로드 페이지를 엽니다: macOS 공식 설치 안내.
  2. 일반 재설치는 USB 없이 복구 모드에서 진행할 수 있습니다. 부팅 USB가 필요한 경우 Apple 공식 안내에서 해당 Mac과 macOS 버전을 지원하는지 확인합니다.
  3. 호환 Mac에서 공식 설치 프로그램을 준비하고 Apple의 createinstallmedia 안내를 따릅니다. 터미널 명령의 대상 볼륨을 잘못 지정하면 다른 저장장치가 지워질 수 있습니다.
  4. 주의: USB를 선택할 때 용량과 이름을 확인하세요. 다른 외장 드라이브를 선택하면 해당 드라이브의 데이터가 삭제될 수 있습니다.

3. USB로 부팅하기

  1. USB를 설치 대상 컴퓨터에 연결하고 컴퓨터를 완전히 종료합니다.
  2. 전원을 켠 직후 부팅 메뉴 키를 여러 번 누릅니다. 흔히 F12, F11, F9, Esc 또는 F8이지만 제조사와 모델마다 다르므로 제조사 안내를 확인하세요.
  3. 목록에서 USB 장치를 선택합니다. UEFI 시스템에서는 'UEFI: USB 이름'처럼 표시될 수 있습니다.
  4. USB가 목록에 없다면 USB를 다시 제작하거나 다른 포트를 사용해 보세요. BIOS 설정 변경은 PC 설명서를 확인한 뒤 진행합니다. 보안 기능을 무작정 끄지 마세요.

4. 운영체제 설치하기

  1. Apple 메뉴의 '이 Mac에 관하여'에서 모델과 Intel/Apple silicon 여부를 확인합니다.
  2. Time Machine 등으로 파일을 백업하고 필요한 계정 정보와 복구 키를 확인합니다.
  3. 단순 재설치라면 USB가 필요하지 않은 경우가 많습니다. 먼저 Apple 공식 macOS 복구 절차를 이용하세요.
  4. 부팅 가능한 설치 USB가 꼭 필요하면 Apple의 해당 macOS 버전 공식 안내에 따라 호환 Mac에서 설치 프로그램을 다운로드합니다.
  5. 용량이 충분한 USB를 연결하고 Apple 공식 안내의 createinstallmedia 명령을 사용합니다. 명령에서 지정한 USB 볼륨이 지워지므로 이름과 대상 디스크를 반드시 확인합니다.
  6. Apple silicon Mac은 전원 버튼을 길게 눌러 시동 옵션을 열고 설치 디스크를 선택합니다. Intel Mac은 모델에 맞는 Option 키 부팅 절차를 사용합니다.
  7. 설치 화면에서 안내를 따릅니다. 디스크 유틸리티에서 디스크를 지우는 것은 필요한 경우에만 진행합니다.
  8. 설치 후 초기 설정을 마치고 백업에서 데이터를 복원합니다.

데이터 보호: '사용자 지정', '디스크 지우기', '파티션 삭제', '포맷' 등의 메뉴는 기존 파일과 운영체제를 삭제할 수 있습니다. 대상 디스크와 파티션을 확인하지 못했다면 여기서 멈추고 도움을 받으세요.

5. 설치 후 확인

  1. 화면의 안내에 따라 재부팅합니다. 설치가 끝났다면 USB를 제거하라는 메시지가 나올 때 제거합니다.
  2. 네트워크, 화면 해상도, 사운드, 키보드, 터치패드, Wi‑Fi 등 주요 장치가 작동하는지 확인합니다.
  3. 운영체제의 공식 업데이트 기능과 PC 제조사의 드라이버를 이용해 업데이트합니다.
  4. 필요한 앱을 공식 출처에서 설치하고 백업을 복원합니다. Windows는 활성화 상태도 확인합니다.

문제 해결

  • USB로 부팅되지 않음: 부팅 메뉴 키, USB 제작 상태, UEFI/레거시 호환성을 확인합니다.
  • 설치 디스크가 보이지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • 설치 후 인터넷이 안 됨: 다른 기기에서 PC 제조사의 공식 네트워크 드라이버를 받아 옮깁니다.
  • 기존 운영체제가 사라짐: 추가로 설치하거나 포맷하지 말고 데이터 복구 가능성을 먼저 확인합니다.
