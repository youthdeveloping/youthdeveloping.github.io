macOS 설치 및 복구 안내

Mac 전용 · 모델 확인 필수

macOS는 Apple Mac 컴퓨터용 운영체제입니다. 설치 방법은 Mac의 연식과 Intel/Apple silicon 여부에 따라 달라집니다.

설치 전 주의사항
일반 PC에 macOS를 설치하는 비공식 방식은 안내하지 않습니다. 본인 소유의 호환되는 Mac에서 Apple 공식 복구·재설치 절차를 이용하세요. 디스크 지우기는 데이터를 삭제하므로 먼저 백업하세요.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. Apple 메뉴의 '이 Mac에 관하여'에서 모델과 칩(Intel 또는 Apple silicon), 현재 macOS 버전을 확인합니다.
  2. 가능하면 Time Machine 또는 다른 방법으로 중요한 파일을 백업하고 Apple 계정 정보와 필요한 암호를 확인합니다.
  3. 업그레이드가 목적이면 Apple의 macOS 호환 모델 및 공식 다운로드 안내에서 해당 Mac이 지원하는 버전을 확인합니다.
  4. 복구가 필요하면 Apple silicon Mac은 전원 버튼을 길게 눌러 시동 옵션을 표시하고, Intel Mac은 모델에 맞는 macOS 복구 키 조합을 사용합니다. 자세한 키 조합은 Apple 공식 안내를 따릅니다.
  5. 복구 화면에서 macOS 재설치를 선택하고 화면의 지시를 따릅니다. 디스크 유틸리티에서 디스크를 지우는 작업은 꼭 필요한 경우에만 진행하세요.
  6. 설치가 끝나면 초기 설정을 완료하고 백업에서 데이터를 복원한 뒤 시스템 설정에서 업데이트를 확인합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.
