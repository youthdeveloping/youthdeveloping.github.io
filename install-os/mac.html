macOS 설치 방법

Apple · 설치 준비부터 설치 후 점검까지

macOS는 호환되는 Apple Mac에서 공식 복구 또는 부팅 가능한 설치 USB로 설치합니다.

시작하기 전에
일반 PC에 비공식 설치하는 안내가 아닙니다. 디스크 지우기는 데이터를 삭제하므로 백업하세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. Apple 메뉴의 이 Mac에 관하여에서 모델과 Intel/Apple silicon 여부를 확인합니다.
  2. Time Machine 등으로 백업하고 Apple 계정 및 필요한 복구 정보를 준비합니다.
  3. 일반 재설치는 USB 없이 복구 모드로 가능할 수 있습니다.
  4. USB가 필요하면 Apple 공식 안내에 따라 호환 Mac에서 정식 설치 프로그램을 다운로드합니다.
  5. createinstallmedia 명령을 사용할 경우 대상 볼륨 이름과 디스크를 두 번 확인합니다. 지정한 USB는 지워집니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: macOS 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. Apple silicon은 전원 버튼을 길게 눌러 시동 옵션을 표시합니다.
  2. Intel Mac은 모델에 맞는 Option 키 부팅 또는 복구 키 조합을 사용합니다.
  3. 설치 디스크가 목록에 나타나면 선택합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. macOS 복구에서 Reinstall macOS를 선택하고 화면 안내를 따릅니다.
  2. 디스크 유틸리티에서 디스크를 지우는 것은 꼭 필요한 경우에만 수행합니다.
  3. 설치할 볼륨을 확인하고 설치를 진행합니다.
  4. 설치 중 전원을 끄지 말고 여러 번 재시작할 수 있도록 기다립니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 초기 설정을 완료하고 백업에서 데이터를 복원합니다.
  2. 시스템 설정에서 소프트웨어 업데이트와 저장 공간을 확인합니다.

6. 문제 해결

  1. 설치 매체가 보이지 않으면 해당 Mac 모델의 지원 버전과 부팅 절차를 확인합니다.
  2. 설치 실패 시 Apple 공식 복구 안내와 인터넷 연결을 확인합니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
