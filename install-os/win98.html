Windows 98 설치 안내

고급 · 구형 PC 전용

Windows 98은 최신 PC가 아니라 당시의 레거시 하드웨어를 위한 운영체제입니다.

설치 전 주의사항
보안 업데이트가 종료된 운영체제입니다. 인터넷에 연결하지 말고, 주 운영체제가 아닌 별도 구형 PC나 가상 머신에서 사용하세요. 최신 UEFI·NVMe·USB 3.x PC에는 설치가 매우 어렵거나 불가능할 수 있습니다.

준비물

  • 중요한 파일의 별도 백업
  • 운영체제에 맞는 정품 또는 공식 설치 이미지
  • 설치 대상 PC와 호환되는 USB/DVD 및 부팅 지원
  • 노트북은 전원 어댑터, 필요시 제품 키와 복구 키

설치 순서

  1. 먼저 PC가 Windows 98 시대의 BIOS, IDE 저장장치, 호환 그래픽·사운드 하드웨어를 지원하는지 확인합니다.
  2. 중요한 파일을 다른 저장장치에 백업합니다. 설치 대상 디스크를 잘못 선택하면 데이터가 삭제될 수 있습니다.
  3. 정품 Windows 98 설치 CD와 해당 PC가 지원하는 부팅 매체를 준비합니다. CD 부팅이 안 되면 호환되는 부팅 디스켓이 필요할 수 있습니다.
  4. BIOS에서 CD 또는 플로피 부팅을 설정하고 설치 매체로 시작합니다.
  5. 설치 프로그램의 안내에 따라 파티션과 파일 시스템을 구성한 뒤 설치를 진행합니다. 디스크 파티션 작업 전 대상 디스크를 반드시 재확인합니다.
  6. 설치 후 메인보드 칩셋, 그래픽, 사운드 등 해당 하드웨어용 드라이버를 설치합니다.

문제 해결 체크리스트

  • USB가 부팅되지 않음: 부팅 메뉴, UEFI/Legacy 모드, USB 제작 방식이 기기와 맞는지 확인합니다.
  • 디스크가 표시되지 않음: 저장장치 컨트롤러 및 공식 드라이버 지원 여부를 확인합니다.
  • Wi‑Fi·소리가 작동하지 않음: PC 제조사 또는 운영체제 공식 저장소에서 호환 드라이버·펌웨어를 확인합니다.
  • 설치 후 부팅되지 않음: BIOS/UEFI 부팅 순서와 설치 대상 디스크를 확인하고, 데이터 삭제 전 복구 방법을 검토합니다.

공식 자료

설치 이미지와 최신 지침은 운영체제 공급자의 공식 웹사이트에서 확인하세요.
