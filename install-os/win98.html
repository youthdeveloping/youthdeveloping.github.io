Windows 98 설치 방법

Windows 구형 · 설치 준비부터 설치 후 점검까지

정품 CD와 당시 하드웨어가 필요할 수 있는 구형 OS입니다.

시작하기 전에
보안 지원 종료. 인터넷에 연결하지 말고 테스트용 구형 PC 또는 격리된 가상 머신에서만 사용하세요.

1. 설치 전 준비

  1. 설치 대상 기기의 정확한 모델명과 CPU 아키텍처, 메모리, 저장 공간 및 UEFI/BIOS 부팅 방식을 확인합니다.
  2. 중요한 파일을 외장 저장장치나 클라우드에 백업합니다. 암호화된 디스크는 복구 키도 별도로 보관합니다.
  3. 안정적인 전원과 인터넷 연결을 준비하고, 설치 이미지와 필요한 라이선스를 공식 출처에서 확보합니다.
  4. 여러 저장장치가 연결되어 있다면 설치 중 혼동하지 않도록 대상 디스크를 미리 확인합니다.

2. USB 또는 설치 매체 만들기

  1. PC 모델·IDE 디스크·CD 드라이브 호환성을 확인하고 데이터를 백업합니다.
  2. 정품 설치 CD와 필요하면 CD-ROM 지원 드라이버가 포함된 부팅 플로피를 준비합니다.
  3. USB에 ISO 파일을 복사하는 것만으로는 부팅 매체가 되지 않습니다. 당시 PC에서는 CD/플로피가 필요할 수 있습니다.
중요: ISO 파일을 USB에 일반 파일처럼 복사하는 것만으로는 보통 부팅 USB가 만들어지지 않습니다. 이미지 기록 기능을 사용하세요. 기록 시 USB 안의 데이터가 삭제될 수 있습니다.

공식 안내: Windows 98 공식 문서 및 다운로드

3. USB/DVD로 부팅하기

  1. BIOS 설정에서 CD-ROM 또는 Floppy를 우선 부팅 장치로 지정합니다.
  2. 부팅 플로피 메뉴가 나타나면 CD-ROM 지원 옵션을 선택합니다.
  3. USB 부팅은 해당 PC가 실제로 지원하는 경우에만 시도합니다.

부팅 메뉴 키는 기기마다 다릅니다. 제조사 로고 화면이나 기기 설명서를 확인하세요. UEFI와 Legacy/CSM 설정은 설치 매체와 기존 시스템 구성에 맞아야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 프로그램을 실행하고 디스크·파티션을 확인합니다.
  2. FDISK 등으로 파티션을 구성해야 한다면 대상 디스크를 재확인하고 변경 후 재부팅합니다.
  3. 설치 프로그램의 안내에 따라 파일 복사, 지역 설정, 사용자 정보와 제품 키 입력을 완료합니다.
데이터 삭제 경고
파티션 삭제, 포맷, 디스크 전체 사용은 기존 파일과 운영체제를 삭제할 수 있습니다. 어떤 디스크인지 확실하지 않다면 진행하지 마세요.

5. 설치 후 설정

  1. 해당 PC용 칩셋·그래픽·사운드 드라이버를 설치하고 장치 관리자 상태를 확인합니다.
  2. 중요 파일을 복원하고 네트워크 연결은 피합니다.

6. 문제 해결

  1. CD 부팅 실패는 BIOS 부팅 순서와 디스크 상태를 확인합니다.
  2. 디스크가 보이지 않으면 IDE 호환성과 케이블을 확인합니다.
  3. 최신 UEFI/NVMe PC에서는 설치가 불가능할 수 있습니다.

문제가 계속되면 PC 모델, OS 버전, 오류 메시지와 부팅 방식을 기록해 공식 문서를 확인하세요. 비밀번호와 제품 키는 공개 게시물에 올리지 마세요.
