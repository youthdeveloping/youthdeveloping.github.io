Windows 98 설치 방법

고급 · 구형 하드웨어 전용 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows 98은 현대 PC보다 당시의 BIOS 기반 PC에서 설치하는 것이 현실적입니다. USB 부팅이 되지 않는 컴퓨터가 많으므로 CD와 부팅 플로피가 필요할 수 있습니다.

설치 전 반드시 읽어 주세요
지원이 완전히 종료된 운영체제입니다. 인터넷에 연결하지 말고, 테스트용 구형 PC나 격리된 가상 머신에서만 사용하세요. 원본 매체와 라이선스를 사용하세요.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. 먼저 PC의 메인보드 모델, CPU, RAM, IDE 디스크, 광학 드라이브를 확인합니다. Windows 98은 최신 UEFI 전용 PC나 NVMe 저장장치와 호환되지 않을 수 있습니다.
  2. 중요한 파일을 별도 저장장치에 복사합니다. 설치 대상 디스크를 잘못 선택하면 데이터가 사라집니다.
  3. 정품 Windows 98 CD와 해당 PC에서 부팅 가능한 CD-ROM 또는 부팅 플로피 디스크를 준비합니다. USB를 단순히 포맷해 ISO 파일을 복사하는 것만으로는 부팅 USB가 만들어지지 않습니다.
  4. 플로피로 부팅해야 한다면 해당 PC에서 읽을 수 있는 정상 부팅 디스크를 사용하고 CD-ROM 지원 드라이버가 포함되어 있는지 확인합니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. PC를 켜고 BIOS Setup 키(화면에 표시되는 키 또는 메인보드 설명서)를 누릅니다.
  2. Boot Order에서 CD-ROM 또는 Floppy를 첫 번째로 설정하고 변경 사항을 저장합니다.
  3. 부팅 메뉴가 나오면 CD-ROM 지원 옵션을 선택합니다. USB 부팅이 가능한 일부 시스템이라도 USB 장치 호환성은 별도로 확인해야 합니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 프로그램이 시작되면 화면의 안내를 읽고 계속 진행합니다.
  2. 디스크가 준비되지 않았다면 파티션 구성은 모델과 기존 데이터에 따라 달라집니다. FDISK 등으로 파티션을 만들기 전 대상 디스크와 백업을 다시 확인하고, 파티션 변경 후에는 재부팅이 필요할 수 있습니다.
  3. 설치 프로그램에서 Windows 설치를 시작하고 지역 설정, 키보드, 사용자 정보 및 제품 키 등 화면에서 요구하는 정보를 입력합니다.
  4. 파일 복사와 재부팅이 진행되는 동안 설치 매체를 제거하라는 안내가 나오기 전까지는 임의로 전원을 끄지 않습니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 메인보드 칩셋, 그래픽, 사운드, 네트워크 등 해당 하드웨어와 Windows 98에 맞는 드라이버를 설치합니다.
  2. 장치 관리자에서 알 수 없는 장치나 오류 표시가 있는지 확인합니다.
  3. 중요한 데이터를 복원하고 필요한 레거시 프로그램만 설치합니다. 보안상 네트워크는 연결하지 않는 것이 좋습니다.

6. 문제 해결 체크리스트

  1. CD 부팅이 안 되면 BIOS에서 광학 드라이브가 인식되는지와 부팅 순서를 확인합니다.
  2. 설치 중 디스크가 보이지 않으면 IDE 호환성과 케이블·디스크 상태를 점검합니다.
  3. 해상도나 소리가 작동하지 않으면 정확한 하드웨어 모델에 맞는 드라이버가 있는지 확인합니다. 최신 드라이버를 임의로 설치하지 마세요.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
