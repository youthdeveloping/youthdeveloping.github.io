Windows 95 설치 방법

고급 · 구형 PC/가상 머신 · 설치 준비부터 완료 후 점검까지

준비설치 매체부팅설치초기 설정

Windows 95는 매우 오래된 프로그램과 하드웨어를 위한 레거시 환경입니다.

설치 전 반드시 읽어 주세요
보안 지원이 종료되었습니다. 인터넷에 연결하지 말고 정품 설치 매체와 라이선스를 사용하세요.

1. 설치 전 준비

  1. 설치할 기기의 정확한 모델명과 CPU 아키텍처(x86/64비트 또는 ARM)를 확인합니다. 모델에 따라 설치 가능한 운영체제가 다릅니다.
  2. 중요한 파일을 외장 드라이브나 클라우드 등 다른 위치에 백업합니다. 암호화된 드라이브를 사용한다면 복구 키도 별도로 보관합니다.
  3. 전원 어댑터를 연결하고 안정적인 인터넷 연결을 준비합니다. 다운로드 용량과 설치에 필요한 저장 공간은 공식 요구 사항에서 확인합니다.
  4. 설치 대상 디스크를 정합니다. 여러 디스크가 연결되어 있다면 설치 중 혼동하지 않도록 불필요한 외장 디스크를 분리하는 것을 고려합니다.
  5. 정품 또는 공식 설치 이미지와 필요한 라이선스·제품 키를 준비합니다. 지원 종료 OS는 인터넷에 연결하지 않는 것을 권장합니다.

2. 설치 USB / DVD 만들기

  1. 호환 구형 PC 또는 격리된 가상 머신을 준비합니다. 가상 머신은 USB/그래픽/사운드 호환성에 제한이 있을 수 있습니다.
  2. 정품 Windows 95 설치 CD와 필요한 경우 부팅 플로피를 준비합니다.
  3. 중요한 파일을 백업하고 설치 대상 가상 디스크 또는 물리 디스크를 확인합니다.
USB 제작 핵심: ISO 파일을 USB에 일반 파일처럼 복사하는 것과 부팅 가능한 설치 USB를 만드는 것은 다릅니다. 이미지 작성 도구에서 ISO/이미지 기록 기능을 사용하세요. 기록 과정은 USB 안의 기존 데이터를 지울 수 있습니다.

공식 자료: Microsoft 지원

3. USB/DVD로 부팅하기

  1. 구형 PC에서는 BIOS에서 CD-ROM 또는 플로피 부팅을 설정합니다.
  2. 가상 머신에서는 가상 광학 드라이브에 설치 ISO를 연결하고 CD/DVD 부팅을 선택합니다.

부팅 메뉴 키는 제조사마다 다릅니다. 전원을 켤 때 화면에 표시되는 키 또는 PC 제조사의 설명서를 확인하세요. UEFI와 Legacy/CSM 방식은 설치 매체 및 기존 운영체제 구성과 일치해야 할 수 있습니다.

4. 운영체제 설치하기

  1. 설치 매체의 안내에 따라 설치 프로그램을 실행합니다.
  2. 필요한 경우 파티션 준비를 진행하되 대상 디스크를 재확인합니다.
  3. 설치 화면에서 지역 설정, 사용자 정보와 라이선스 정보를 입력합니다.
  4. 설치가 끝나고 재부팅되면 부팅 순서를 원래 디스크로 돌립니다.
디스크 삭제 경고
파티션 삭제, 포맷, '디스크 전체 사용'은 파일과 기존 운영체제를 지울 수 있습니다. 대상 디스크를 확실히 구분할 수 없다면 다음 단계로 진행하지 마세요.

5. 첫 부팅과 초기 설정

  1. 해당 PC 또는 가상 머신에 맞는 레거시 드라이버를 적용합니다.
  2. 필요한 구형 프로그램만 설치하고 네트워크를 비활성화합니다.

6. 문제 해결 체크리스트

  1. USB 부팅을 지원하지 않으면 CD 또는 부팅 플로피를 사용해야 할 수 있습니다.
  2. 현대 하드웨어에서는 설치 자체가 불가능할 수 있으므로 가상 머신을 고려합니다.

문제가 계속되면 오류 메시지 전체, PC 모델, 설치하려는 OS 버전, 부팅 방식(UEFI/Legacy)을 기록해 공식 지원 문서를 확인하세요. 제품 키나 계정 비밀번호는 공개 게시물에 올리지 마세요.
