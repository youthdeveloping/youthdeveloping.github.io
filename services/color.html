색상 도구

색상 선택기에서 고른 색의 HEX 및 RGB 표현을 확인하는 기초 디자인 도구입니다.

색상 도구 사용 안내

어떤 상황에 사용할 수 있나요?

웹사이트의 배경색, 버튼 강조색, 아이콘 색상을 정하고 CSS 색상값을 복사해 프로젝트에 적용할 때 활용할 수 있습니다.

사용 순서

  1. 색상 선택기를 눌러 색을 고릅니다.
  2. 표시된 HEX 및 RGB 값을 확인합니다.
  3. 필요한 값을 CSS에 복사해 적용합니다.

사용 예시

예: 색상 선택기에서 흰색을 고르면 HEX 값은 #FFFFFF, RGB 값은 rgb(255, 255, 255)입니다. CSS에서는 color: #FFFFFF;처럼 사용할 수 있습니다.

기능 범위와 주의사항

색상값을 보여주는 도구이며 텍스트와 배경의 접근성 대비를 자동으로 검증하지 않습니다. 실제 페이지에서는 작은 글자, 버튼, 포커스 표시의 대비를 별도로 확인하세요.

자주 묻는 질문

색상 코드가 적용되지 않으면 # 기호를 포함한 6자리 HEX 형식인지, CSS 속성에 올바르게 넣었는지 확인하세요.
