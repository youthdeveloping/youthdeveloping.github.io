# Termux v0.118.0 — Source archive

This directory documents the source archive supplied for the YouthDeveloper Termux page.

- Project: Termux Android application
- Version: v0.118.0
- Upstream project: https://github.com/termux/termux-app
- Upstream releases: https://github.com/termux/termux-app/releases
- Official project website: https://termux.dev/

## Important

The supplied `termux_v0.118.0.zip` archive has **not** been committed into this repository as a binary file. This GitHub Pages repository is a website repository, and the archive contains `app/dev_keystore.jks`, a potentially sensitive signing keystore. Do not publish that keystore without confirming its ownership and whether it is intended to be public.

For a clean source import, extract the archive, review/remove private signing material, preserve the upstream license and notices, and commit the reviewed source tree under this directory. The original upstream project remains the authoritative source.
