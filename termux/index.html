Termux

Android 기기에서 Linux 명령줄 환경을 사용하고 다양한 개발 도구를 설치할 수 있는 터미널 에뮬레이터입니다.

공식 앱 저장소 공식 홈페이지 패키지 저장소

Linux 도구

패키지 관리자를 통해 셸, Git, Python 등 다양한 도구를 설치할 수 있습니다.

개발 환경

Android 기기에서 코드를 작성하고 명령줄 기반 개발 작업을 진행할 수 있습니다.

오픈 소스

소스 코드, 빌드 방법, 이슈 및 기여 안내는 공식 GitHub 저장소에서 확인하세요.

안내: 이 페이지는 Termux 프로젝트를 소개하는 페이지이며, Termux 앱 자체를 웹 브라우저에서 실행하지는 않습니다. 프로젝트의 원본 소스와 최신 설치 안내는 공식 저장소를 확인해 주세요.

Termux는 해당 프로젝트의 제작자와 기여자들이 개발합니다. 청소년 개발자 페이지는 안내 목적으로 제공되며 공식 Termux 프로젝트와 별도로 운영됩니다.
