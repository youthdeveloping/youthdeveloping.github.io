# YouthCraft 개별 도구 확장 로드맵

> 목표: 13개 도구를 서로 다른 전문 작업에 맞게 확장합니다. 이 문서는 구현 계획이며, 아래 기능이 이미 구현되었다는 뜻은 아닙니다.
>
> 원칙: 현재의 YouthCraft 브랜드와 어두운 작업실 UI를 유지하고, 실제로 동작하는 기능부터 단계적으로 추가합니다. 상용 제품의 이름·로고·전용 UI를 그대로 복제하지 않고, 일반적인 편집 작업 흐름과 기능을 참고해 독자적으로 구현합니다.

## 1. PhotoCraft — 이미지 편집

**목표:** 레이어 기반 래스터 이미지 편집기.

- [ ] 레이어: 순서 변경, 표시/숨김, 잠금, 이름 변경, 복제, 그룹
- [ ] 선택·이동·정렬·스냅·가이드·눈금자
- [ ] 자르기 프레임과 비율 프리셋, 회전 핸들, 크기 조절 핸들
- [ ] 브러시·지우개·스포이드·채우기 도구
- [ ] 텍스트 편집: 글꼴, 크기, 굵기, 정렬, 줄 간격
- [ ] 마스크 및 비파괴 조정 레이어 기초
- [ ] 밝기·대비·채도 외에 색조, 감마, 흑백, 블러, 선명도
- [ ] PNG/JPEG/WebP 내보내기, 품질·배경 투명도 선택
- [ ] 대용량 이미지 메모리 관리와 복원 테스트

**완료 기준:** 레이어를 편집한 뒤 프로젝트로 저장하고 다시 열어 편집 상태가 복구되며, 내보낸 이미지가 화면 결과와 일치합니다.

## 2. VectorCraft — 벡터 그래픽

- [ ] 펜·노드 편집, 직선/곡선 및 베지어 핸들
- [ ] 도형·선·다각형·별·화살표
- [ ] 채우기/획, 획 굵기, 점선, 끝 모양, 그라데이션
- [ ] 정렬·분배·그룹·경로 순서·불리언 연산 기초
- [ ] SVG 가져오기 및 안전한 SVG 내보내기
- [ ] 확대/축소, 패닝, 스냅, 정렬 가이드
- [ ] PNG 렌더링 크기 선택

**완료 기준:** 여러 벡터 객체를 선택·수정하고 SVG로 내보낸 뒤 다시 열었을 때 위치와 스타일이 유지됩니다.

## 3. FilmCraft — 영상 편집

- [ ] 미디어 가져오기와 클립 라이브러리
- [ ] 다중 트랙 타임라인, 클립 이동·자르기·분할·삭제
- [ ] 재생 헤드, 프레임 단위 이동, 구간 시작/끝 표시
- [ ] 영상·오디오 파형과 음소거/볼륨
- [ ] 제목·자막·기본 전환 효과
- [ ] 화면 비율 프리셋과 미리보기 해상도
- [ ] 내보내기 설정 및 지원 여부 안내
- [ ] 브라우저 인코딩 한계를 고려한 처리 방식 검증

**완료 기준:** 타임라인 편집과 프로젝트 저장/복원이 동작하고, 실제로 지원되는 출력 방식만 사용자에게 제시합니다. 브라우저에서 인코딩이 지원되지 않으면 기능이 있는 것처럼 표시하지 않습니다.

- [ ] 비파괴 보정값 프로젝트 저장

- [ ] 원본 해상도 내보내기와 EXIF 처리 안내

**완료 기준:** 슬라이더 변경이 즉시 미리보기에 반영되고 원본을 보존한 채 조정값을 저장·복구합니다.

## 5. PdfCraft — PDF 도구

- [ ] PDF 가져오기 및 페이지 썸네일
- [ ] 페이지 순서 변경·회전·삭제
- [ ] 여러 PDF 병합 및 페이지 범위 선택

- [ ] 문서 메타데이터 편집

- [ ] 암호화 PDF, 폰트, 대용량 파일의 제한 안내

**완료 기준:** 페이지 작업 결과를 실제 PDF로 내보내고, 다시 열어 페이지 수와 순서가 정확한지 확인합니다. 브라우저 인쇄만 지원되는 경우 정식 PDF 편집 기능과 구분합니다.

## 6. EffectCraft — 모션·효과

- [ ] 프레임 타임라인과 프레임 추가/복제/삭제
- [ ] 레이어별 위치·크기·회전 키프레임

- [ ] 프레임 수·크기 제한과 성능 안내

**완료 기준:** 미리보기 재생과 프레임 저장이 일치하고, 지원하지 않는 애니메이션 파일 형식은 내보내기 선택지에 노출하지 않습니다.

- [ ] CSV 가져오기/내보내기 및 인코딩 처리
- [ ] XLSX 지원은 수식·서식 호환성 테스트 후 제공
- [ ] 큰 표의 렌더링 성능과 데이터 복구

**완료 기준:** 편집·수식 계산·CSV 왕복 저장이 정확하고, 잘못된 수식과 데이터 형식을 식별할 수 있습니다.

## 권장 구현 순서

### 1단계 — 기반과 신뢰성
1. 공통 프로젝트 저장/불러오기 구조를 도구별 어댑터로 정리합니다.
2. 실행 취소/다시 실행, 오류 상태, 키보드 조작을 공통 규칙으로 만듭니다.
3. 각 도구의 현재 기능을 테스트하고, 실제 동작하지 않는 버튼이나 잘못된 내보내기를 먼저 수정합니다.

### 2단계 — 빠르게 완성도를 높일 도구
1. **LightCraft:** 보정 도구와 전후 비교
2. **WordCraft:** 리치 텍스트·찾기/바꾸기·문서 저장
3. **GridCraft:** 셀 편집·기본 수식·CSV 왕복
4. **DesignCraft:** 객체·레이어·템플릿·내보내기
5. **VectorCraft:** 경로·노드·SVG 가져오기/내보내기

### 3단계 — 전문 편집 기능
1. **PhotoCraft:** 레이어·마스크·브러시·비파괴 편집
2. **DeckCraft:** 다중 슬라이드·발표 모드
3. **FigCraft:** 컴포넌트·오토 레이아웃·프로토타입
4. **SoundCraft:** 파형·구간 편집·오디오 효과

### 4단계 — 미디어 처리와 정확도 검증
1. **FilmCraft:** 타임라인과 지원 가능한 출력 파이프라인
2. **EffectCraft:** 키프레임·이징·애니메이션 출력
3. **PdfCraft:** 페이지 단위 편집과 실제 PDF 처리
4. **CADCraft:** 정밀 좌표·치수·CAD 교환 형식

## 구현 시 지킬 원칙

- 기능이 완성되기 전에는 완성된 것처럼 표시하지 않습니다.
- 저장·불러오기·내보내기는 실제 파일을 사용해 테스트합니다.
- 원본 파일을 덮어쓰지 않도록 기본 동작을 안전하게 설계합니다.
- 이미지·영상·오디오 처리는 가능하면 사용자의 브라우저 안에서 수행합니다.
- 외부 라이브러리를 추가할 때는 라이선스, 번들 크기, 보안과 오프라인 동작을 확인합니다.
- 모든 도구에서 공통 디자인은 유지하되, 도구별 작업 방식과 전문 기능은 분명히 구분합니다.
